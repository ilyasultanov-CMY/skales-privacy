Skales — Политика конфиденциальности

Дата публикации: 25 октября 2026 г.

1. Общие сведения

Skales — персональная интеграция, используемая с DeepSeek Harness для работы с сервисами Google Workspace по запросу пользователя. Ответственный за интеграцию: Илья Султанов. Контактная почта: ilyasultanov@gmail.com.

Эта политика относится к интеграции Skales и не описывает обработку данных самим сервисом Wix.

2. Какие данные используются

После авторизации через Google OAuth интеграция может получать доступ к данным Gmail, Google Calendar, Google Drive, Google Docs и Google Sheets в пределах разрешений, которые пользователь видит и подтверждает на экране согласия Google.

Интеграция использует эти данные только для выполнения действий, запрошенных пользователем: чтения, поиска, создания, изменения или отправки содержимого. Никакие действия не выполняются скрыто от пользователя или для посторонних целей.

3. Как используются данные

Данные не продаются, не используются для рекламы и не передаются третьим лицам для их самостоятельных целей.

Обработка происходит в локальном окружении DeepSeek Harness. Для выполнения запроса необходимое содержимое может передаваться сервисам Google и выбранному пользователю поставщику ИИ в DeepSeek Harness. Их собственные политики конфиденциальности применяются к обработке данных этими сервисами.

4. Где хранятся данные

Илья Султанов не размещает отдельный сервер или базу данных для хранения содержимого пользователя. Документы, письма и события остаются в соответствующих сервисах Google.

Учётные данные OAuth сохраняются локально на устройстве пользователя в зашифрованном виде средствами Google Workspace CLI. DeepSeek Harness и операционная система могут создавать локальные рабочие кэши, необходимые для выполнения запросов.

5. Отзыв доступа и удаление данных

Пользователь может отозвать доступ Skales в любой момент на странице https://myaccount.google.com/permissions. После отзыва доступа интеграция не сможет получать новые данные из Google-аккаунта.

Локальные сохранённые учётные данные можно удалить командой gws auth logout. Содержимое, созданное в сервисах Google, удаляется пользователем в соответствующих сервисах Google.

6. Изменения политики

При изменении порядка обработки данных текст этой страницы может быть обновлён. Актуальная дата публикации указывается в начале документа.
